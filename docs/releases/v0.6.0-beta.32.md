# Morrow Mail 0.6.0-beta.32

This beta adds native, searchable Label / Folder Managers and makes choosing destinations easier in both SwiftUI and WinUI. It includes the automatic local folder catalogs introduced in beta.31.

## Changes

- **Label / Folder Manager:** browse the owning mailbox's hierarchy, search names or full paths, create at the root or under a parent, rename, move to another parent, and review deletion. System/unavailable folders are protected; parent choices exclude the selected folder and its descendants.
- **Email organization:** message context menus and reader actions expose Move, Gmail Labels, Create and Manage where applicable. Gmail's custom-label checklist retains selections while filtering and submits only explicit add/remove deltas in one reviewed request, preserving Inbox and other owners. Outlook/IMAP messages retain single-folder moves.
- **Searchable menus:** destination and Parent popups have their own name/path search, empty states and keyboard selection. These filters are independent of the sidebar filter and do not download mail.
- **Create from an email:** review folder/label creation first, optionally select the created destination, then review the separate message assignment. Creating a folder does not silently move mail.
- **Offline and failure handling:** managers use account-scoped cached hierarchy metadata alongside selectable sidebar names. Failed reviews retain form inputs. IMAP TCP connection failures now show the safe provider error rather than an incorrect workspace-storage error.

Provider changes still require an explicit owning mailbox, server-validated destinations, write permission and confirmation. Cached names do not authorize writes. Uncertain provider writes never retry automatically.

## Validation and limits

The existing paired workflow must pass the full Node-free Rust checks, both native builds/acceptance, Windows fresh/owned/restart walkthrough and fictional-mail benchmark before either download becomes public. The existing publisher validates same-run/same-attempt provenance, archive checksums and the manifest signature against the unchanged pinned key. No test waiver applies. Tagged CI and public-asset verification are recorded in VERIFICATION.md.

Pre-tag validation includes the complete 184-test Rust suite in serial and normal parallel execution, 90 repeated CLI fixture test executions, native production-service acceptance and paired source CI. The [1–2 October walkthrough](../WALKTHROUGH-2026-10-01.md) separates actual macOS/Parallels interaction from automated provider/model fixtures. It is not a complete manual walkthrough of these tagged binaries.

**Known acceptance issue:** Windows source CI intermittently timed out at the reader's unchanged 25-second WebView2 controller-ready gate. A same-source rerun passed, but the cause remains unresolved. The failure is retained in the verification record. This release does not claim that the timeout was fixed. Parallels guest-input tooling also blocked the remaining local interactive checks.

Full live-account, clean-machine, accessibility and installed-updater restart/rollback acceptance remain outstanding. Folder deletion impact remains provider-specific: Gmail removes labels without deleting mail; Outlook deletion affects contents and children; IMAP deletion removes the selected mailbox's messages. Gmail subtree rename/move is limited to 50 labels per review and can partially apply. Cached mail and local drafts remain separate from provider deletion.

Catalog caching does not download every message or attachment. Full provider delta/deletion mirroring, attachment/CID viewing, cross-account transfers and bulk message moves remain unsupported. Tests use isolated fictional workspaces, loopback provider fixtures and generated updater apps/keys; no real mail, calendar event or paid model request was submitted for this release.

macOS is ad-hoc signed without notarization; Windows is unsigned. Full live-account acceptance remains outstanding. This is an experimental prerelease.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. Older macOS versions predating the beta.30 update-quit fix may still require one manual Quit during this upgrade. Keep the separate mailbox workspace backed up and run only one client against it.
