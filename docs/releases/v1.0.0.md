# Morrow Mail 1.0.0

- Copy a local link to an email so you can reopen it from a note or calendar entry on the same Morrow profile. [Local message links](https://github.com/Coke1120/Morrow-Mail/issues/653)
- Offer two available times from your checked calendars in a reply, quote only the passage you selected, or show a selected timestamp in your local time. [Availability](https://github.com/Coke1120/Morrow-Mail/issues/657) · [Selected quotes](https://github.com/Coke1120/Morrow-Mail/issues/659) · [Local time](https://github.com/Coke1120/Morrow-Mail/issues/660)
- Set a reminder to follow up on an already sent message. If Morrow cannot verify whether a reply arrived, it asks you to check the mailbox. [Follow-up reminders](https://github.com/Coke1120/Morrow-Mail/issues/658)
- Save selected attachments from several messages to a single folder, or forward selected Local Folders messages as original email attachments in one draft. [Save attachments](https://github.com/Coke1120/Morrow-Mail/issues/661) · [Forward originals](https://github.com/Coke1120/Morrow-Mail/issues/663)

Opening stored links from external notes and calendar apps, and time saved in those workflows, remain unverified.
