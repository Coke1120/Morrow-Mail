# Compare quotes and resume the right draft

- Open two messages in separate reader windows to compare their PDF attachments side by side. In Compose, preview a newly attached PDF before you save the draft. [Reader comparison](https://github.com/Coke1120/Morrow-Mail/pull/628) · [Compose preview](https://github.com/Coke1120/Morrow-Mail/pull/629)
- Find downloaded drafts by recipient across pages, including a recipient beyond the first address. With the recipient column hidden, you can still preview the full recipient list before opening the draft. [Recipient preview](https://github.com/Coke1120/Morrow-Mail/pull/630) · [Draft search](https://github.com/Coke1120/Morrow-Mail/pull/631)
- Apply formatting to selected text in Compose and undo edits. Clear the toolbar search to return to the Inbox. When a single mail action is left to undo, the confirmation identifies the message by sender and subject. [Compose](https://github.com/Coke1120/Morrow-Mail/pull/625) · [Inbox search](https://github.com/Coke1120/Morrow-Mail/pull/626) · [Undo](https://github.com/Coke1120/Morrow-Mail/pull/627)
- Native notification previews filter invisible control characters. Pending IMAP notifications are discarded if the account is invalidated before delivery. [Notification previews](https://github.com/Coke1120/Morrow-Mail/pull/623) · [IMAP notifications](https://github.com/Coke1120/Morrow-Mail/pull/624)

The Windows and macOS release builds now run in parallel. Publication waits for both builds and verifies the artifacts from the same run. [Release workflow](https://github.com/Coke1120/Morrow-Mail/pull/622)
