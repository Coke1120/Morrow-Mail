# Morrow Mail 0.6.0-beta.29

This beta fixes Windows dark-theme contrast and brings its Inbox and Outbox presentation closer to the macOS design. It also includes the default send delay, server folder browsing and one-minute provider Trash undo added since beta.28.

## Changes

- **Windows theme:** paint an opaque, live theme background under WinUI's translucent navigation and content surfaces. Switching Light, Dark or Match device retains readable content across mail, Settings and Outbox. System high-contrast resources remain in charge.
- **Windows layout:** show Morrow above its tagline, use the macOS search-button order, place Sync on the right and center paging between Previous/Next. The empty reader has an accent envelope, title and secondary text, including after its selected message is removed. Outbox matches the macOS heading, mailbox/Refresh row and empty-state copy while retaining scheduling safety guidance.
- **Trash undo:** the direct provider Trash button has a 60-second Undo button and Cmd+Z / Ctrl+Z. Text fields retain text undo. Account-bound, single-use undo restores the confirmed original provider location; failed or uncertain writes never replay automatically.
- **Default send delay:** Settings accepts Immediately (default) or 1–6 hours across accounts. Compose reviews the exact future time and freezes the owner, To/Cc/Bcc, body, footer and headers. Pending mail appears in Outbox. Changing the preference does not alter existing schedules; cancelling an awaiting schedule unlocks its draft.
- **Server labels and folders:** browse Gmail custom labels and selectable Outlook/IMAP folders using downloaded messages. Refreshing the catalog reads names only; it does not mirror the complete server mailbox. Moves still require the owning mailbox, provider write permission and the existing review.

## Validation and limits

The tagged workflow must pass the complete Node-free Rust checks on both platforms, native macOS acceptance, Windows packaging/UI/persistence/reader checks and the fictional-mail benchmark before the existing publisher makes either platform public. The Windows native regression switches Light/Dark and verifies that the root has a matching opaque background. Both downloads and the update manifest retain same-run signed provenance and the existing pinned update key; no test waiver applies.

Scheduled sends run only while Morrow is open and have a 15-minute late grace. Interrupted or uncertain delivery requires explicit review and is never automatically resent. Attachments, CID images and full provider delta/deletion synchronization remain unsupported. Fixtures and a limited Parallels visual walkthrough do not establish complete live-account, accessibility or clean-machine acceptance.

macOS is ad-hoc signed without Apple notarization; Windows is unsigned. This is an experimental prerelease.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. Back up the separate mailbox workspace before updating and run only one client against a workspace.
