# Morrow Mail 0.6.0-beta.30

This beta adds reviewed provider label/folder management, local sidebar filtering and a resizable Windows sidebar. Today gains an immediate summary action; connection settings refresh automatically and macOS completes the update quit without a separate manual Quit.

## Changes

- **Labels and folders:** create, rename, delete and move custom Gmail labels or Outlook/IMAP folders to another parent from either native client. Reviews show the owning mailbox and provider-specific impact. System labels/folders are protected. Folder context menus preselect the existing reviewed action to move a selected message into that destination.
- **Sidebar:** filter loaded label/folder names locally without changing the selected mailbox or message. Windows supports dragging its right divider, arrow keys and View's wider/narrower actions with a persisted bounded width; full-name tooltips help with long names. macOS retains native split resizing.
- **Today:** clearer downloaded-mail totals, report headings/status and empty states. Summarize now reviews one mailbox, permitted downloaded data and the configured model, then saves an immediate P0–P4 report. Automatic triggers can remain off; the existing schedule is unchanged and failed paid requests do not retry automatically.
- **Settings:** Mail accounts and Calendar refresh local connection metadata automatically while open, including browser sign-in/reconnect return. Unsaved credentials/preferences and mail selection/paging remain intact; the status poll does not sync mail, load calendar events or call AI.
- **macOS updates:** Install and Restart dismisses Settings and waits for its completed dismissal before terminating, allowing the existing installer to wait for both UI and service, install and restart. Ordinary close/edit/write guards remain.

## Validation and limits

The release uses the existing paired workflow and publisher. Both platform jobs must pass the complete Node-free Rust checks, native packaging/acceptance and Windows UI/persistence/reader checks plus fictional-mail benchmarks before either download is published. Signed provenance, manifest verification and the existing pinned update public key remain required; no test waiver applies. Verification details and CI evidence are recorded in VERIFICATION.md.

Provider management uses explicit write permission and account/connection-bound single-use reviews; stale hierarchy or connection changes require another review. Gmail subtree rename/move is limited to 50 labels per review and can partially apply because Gmail offers no atomic subtree rename. Gmail label deletion retains messages and inferior label names. Outlook folder deletion affects its contents and children. IMAP deletion permanently removes the selected mailbox's messages while inferior mailbox names remain; hierarchy moves use its delimiter and verify UIDVALIDITY. Message moves still require MOVE + UIDPLUS. Cached messages, Pending, local overrides and drafts are retained. Lost or failed writes never replay automatically.

Folders show downloaded mail, rather than a complete server mirror. Cross-account transfers, bulk message moves, attachments/CID viewing and continuous provider delta/deletion reconciliation remain unsupported. Scheduled sending still requires Morrow to be open and keeps the 15-minute late grace and uncertain-delivery review.

Automated acceptance uses isolated fictional workspaces, TLS provider fixtures and generated updater keys/apps. It does not establish full live-account, clean-machine, accessibility or a real signed installed-app update walkthrough. macOS is ad-hoc signed without notarization; Windows is unsigned. This is an experimental prerelease.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. An older installed macOS version may still need one manual Quit during this upgrade; subsequent update quits use this fix. Back up the separate mailbox workspace and run only one client against it.
