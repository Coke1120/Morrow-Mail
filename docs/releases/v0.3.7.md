## Reading a message

If a foreground download fails before any body is available, the reader shows
Retry download and leaves the message unread. A server response with no
requested message source, including an IMAP FETCH that returns flags only, an
empty result, or a different message, uses that same failure. A summary alone
does not count as a successful open.

Partial cached content stays visible with a download warning, and Retry can
finish the body. A complete cached body stays readable if a later metadata
refresh fails.

## Gmail sync

Each Gmail folder pass reads at most 20 full messages. That budget covers
history, the first sync, and cache checks together. Unfinished message ids
resume from the saved place on the next pass or after a restart. Opening a
message goes ahead after the current read. A request already in flight is not
cancelled. Writes, sends, and sign-in permissions stay as they are.

## Signatures across mailboxes

Switching Compose From to another mailbox keeps the rest of the message,
including formatting and links. A signature you edited stays. Only an untouched
automatic signature follows the new mailbox, including a multiline HTML
signature, or is removed when that mailbox has no signature.

Changing From to another alias on the same mailbox still follows signatures as
plain text. A markup-only edit on that path can still be replaced. This release
leaves that path as it is.

## Conversations

A Gmail message stored under more than one label appears once in a conversation,
matched by its provider message id on the same account. The copy you opened
stays selected. Folder records stay stored. Other messages, other accounts,
rows without a provider id, and drafts stay separate, including when the RFC
Message-ID matches. One message still has no Earlier section.
