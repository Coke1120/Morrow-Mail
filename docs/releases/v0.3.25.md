## Folder chips without duplicates

Mailbox folder chips show one canonical name per enabled role (Inbox, Sent,
Drafts, Starred, Unread, Trash, Junk, Archived, plus All Mail or Important when
enabled). Sent Items, Sent Mail and casing variants share one Sent chip. Chips
stay in a fixed order and belong to the selected mailbox—they never merge every
account's raw folder names. Selecting another folder with the same role keeps
that real folder selected; all server folders remain available in the sidebar.

All Account Mail keeps its Inbox, Outbox, Starred and Unread sidebar views.
Cross-account Sent, Drafts, Trash, Junk and Archived chips remain unavailable.

## Consistent colorful sidebar icons

Expanded IMAP, Gmail and Outlook accounts share the same colorful folder icons
for known roles (including wellKnown / wellKnownName aliases). Custom folders
keep a generic folder icon. Saved account expansion choices are unchanged.

## Integration and validation limits

Synthetic checks cover chip role dedupe, sidebar icon aliases, Features catalog
parity and related mail-view / folder scripts. Publication uses the existing
Windows-then-macOS pipeline. Windows remains unsigned; macOS remains ad hoc
signed without Developer ID or notarization. Live mail accounts and installed
updater transitions remain unverified. No signing roots, secrets or release
gates are changed.
