## Bounded residual mail journal and mailbox work

Residual journal and mailbox work stays within bounded batches. Refresh uses a
scoped cursor. See the
[residual mail performance ADR](../adr/2026-11-01-residual-mail-performance.md).

## Bot delete and halted delivery

Deleting a bot forgets its webhook credential before removing its grant. If the
grant cannot be removed from storage, access and the credential are retained.
Settings shows storage-related delivery halts; saving settings or toggling
access does not resume a halted bot.

## Mark category as read feedback

When a category has no unread mail, Mark category as read shows
`Already read.` and the button stays disabled.
