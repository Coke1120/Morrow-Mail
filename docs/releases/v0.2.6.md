# Morrow Mail 0.2.6

This release introduces authenticated macOS update downloads using the existing legacy Ed25519 signing identity. The updater verifies the signed manifest, archive size/hash and bundle integrity, stages privately, waits for orderly shutdown, and retains a recovery backup during replacement. Windows continues to use its existing electron-updater flow and unsigned installers.

## macOS installation and migration

- The ARM64 app is ad hoc signed for integrity. It is **not Apple Developer ID signed or notarized**. Ed25519 authenticates release bytes; it does not grant macOS execution permission.
- Existing Electron 0.2.4/0.2.5 installations require a **one-time manual bridge installation** of 0.2.6. Quit Morrow before replacing the app; retain existing mail/profile data. This release cannot retrofit the old updater before installation.
- Subsequent update downloads are authenticated, but unattended installation is **not guaranteed**. macOS security policy and installation permissions may require manual installation through Finder and normal system prompts. The updater never removes quarantine or directly executes a rejected candidate.
- Standard writable root:admin `/Applications` installations are eligible for checks; unsupported permissions or policy assessment lead to explicit manual handoff. An uncertain restart retains recovery files rather than overwriting a potentially running app.

## Release verification

The release workflow builds both platforms without publishing, checks the final macOS archive, signs its manifest with the existing Actions secret, verifies paired feeds/artifacts and source provenance, and downloads all draft assets to verify their bytes before promotion. Missing/mismatched signing credentials or integrity failures stop publication. A build-host policy rejection is reported as a manual-install limitation, not an execution approval.

See [Signed updates](../SIGNED_UPDATES.md) for migration, recovery and native validation limits. A successful release build does not itself prove an end-to-end update on every Mac.
