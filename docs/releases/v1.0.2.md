# Morrow Mail 1.0.2

- Timeline identifies the current account and selected/included counts, and uses local exact-quote matching to avoid resending duplicated thread history. Unique text and original messages are retained; the preview reports serialized bytes rather than billed tokens. Case search stays limited to the current account’s downloaded mail. [#710](https://github.com/Coke1120/Morrow-Mail/pull/710) · [#711](https://github.com/Coke1120/Morrow-Mail/pull/711)
- Compose adds local Find & Replace and a right-click action to translate selected text you wrote. The translation is reviewed before it goes to your saved AI connection; you can edit the proposed translation before applying it and undo the change. [#705](https://github.com/Coke1120/Morrow-Mail/pull/705) · [#709](https://github.com/Coke1120/Morrow-Mail/pull/709)
- Reader adds a private local checklist and opens an editable calendar draft from an explicit date/time selection. The calendar draft does not invite anyone or save until you choose Save. [#706](https://github.com/Coke1120/Morrow-Mail/pull/706) · [#707](https://github.com/Coke1120/Morrow-Mail/pull/707)
- The send preview warns about explicitly named missing attachments without blocking send, and PDF attachment preview uses an A4-style window that fits the display. Reader right-click actions replace the old quote, copy-local-link and local-time controls; sidebar actions wrap instead of overlapping. [#694](https://github.com/Coke1120/Morrow-Mail/pull/694) · [#696](https://github.com/Coke1120/Morrow-Mail/pull/696) · [#700](https://github.com/Coke1120/Morrow-Mail/pull/700) · [#703](https://github.com/Coke1120/Morrow-Mail/pull/703) · [#704](https://github.com/Coke1120/Morrow-Mail/pull/704)

- Reader's Save as lets you choose a local attachment name, keeps the original extension, and leaves the email attachment unchanged. [#708](https://github.com/Coke1120/Morrow-Mail/pull/708)

Windows x64 is available as an unsigned installer and portable executable. The macOS ARM64 app is ad hoc signed, not notarized. See [packaging and updater notes](https://github.com/Coke1120/Morrow-Mail/blob/v1.0.2/docs/PACKAGING.md).
