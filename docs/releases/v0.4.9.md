# Mail text, skill routing and calendar selections

This patch includes PR #556.

- The message list keeps the same stored subject and snippet as the reader for
  persisted server mail. It does not run a second encoding repair. Pending local
  drafts keep their existing repair behavior. No cache-wide rewrite is performed.
- Typed chat runs a skill only when the whole message is its name or id, or `run`
  followed by that name or id. A longer message mentioning a skill stays a chat
  answer. Explicit skill chips continue to select the skill by id.
- Outlook calendar enumeration refuses incomplete lists, including more than five
  pages, repeated next links and links that cannot be followed. Saved selections
  remain unchanged on failure. Google already uses the same completeness rule.
  Saved calendar checks are restored in full instead of stopping at 100.
- Domain CC/BCC settings preserve commas inside quoted recipient display names.
  Invalid addresses are rejected before any preferences are saved.

## Validation and limits

Synthetic host and renderer regressions cover stored mail text, exact skill
routing, explicit skill ids, incomplete Outlook pagination, calendar selection
persistence and recipient parsing. The full `npm run check` passed on the PR
source. Synthetic Chrome checks also passed for the updated Features copy in
light/dark and narrow layouts, 101 calendar selections in real localStorage,
quoted recipients and invalid-address rejection. No real mailboxes, calendar
providers, AI services or saved user credentials were used.

The release candidate gate is the full aggregate check and Linux/Windows CI.
Native installed-app and updater transitions are not newly verified here.
Windows remains unsigned. macOS remains ad hoc signed, without Developer ID or
notarization. The paired workflow validates source provenance, asset hashes,
updater feeds, native Mac archive integrity and the Ed25519 manifest before
publication. Those checks do not establish Gatekeeper trust or authorize
installation. Existing releases and signing roots stay unchanged.
