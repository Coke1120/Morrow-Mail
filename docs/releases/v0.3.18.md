## Mail columns and sorting

Inbox, Sent, Drafts, other cached folders and All Account Mail show Date,
Recipient, Sender and Subject headers. Select a header to sort; select it again
to reverse direction. The choice is remembered on this device. Changing order
returns to page one and keeps the reader open; selection is retained only for
messages on the new page. Headers and rows scroll horizontally together in a
narrow pane, with compact and comfortable layouts preserved.

Sorting covers all matching downloaded messages before pagination. Local search
also sorts before its existing 100-result cap. The page filter still filters
loaded rows only. Outbox keeps scheduled order and disables the sort headers.

Recipient shows the full To list and sorts by its first entry; Cc/Bcc are not
substituted. Sender uses a saved display name when available, otherwise cached
From text. Date uses the existing stored timestamp, including local draft save
time. Empty text, equal keys and missing display dates have deterministic handling.
Text ordering uses SQLite NOCASE, with ASCII folding and binary non-ASCII order,
rather than locale collation. Text sorts scan matching metadata and may cost more
on a large cache than the indexed newest-first order.

## Google first-use setup

A fresh profile without accounts or an existing Google client offers Import
Google Console JSON and Later. Later, Escape and closing the dialog remember
the choice for this profile. Accounts keeps a visible reminder pointing to the
existing Advanced Desktop-client importer. Profiles with accounts or a bundled,
imported or environment client keep their existing setup path.

Import remains an explicit local action. It does not start authorization or prove
that Google Cloud setup, test-user access, consent or verification is complete.
Cancelled or invalid files leave retry available. Closing the prompt does not
cancel an already-open native picker. If profile storage is unavailable, dismissal
lasts only for the current window.

## Validation and distribution

This release includes [#449](https://github.com/Coke1120/Morrow-Mail/pull/449) and
[#450](https://github.com/Coke1120/Morrow-Mail/pull/450). The combined source passed
the full offline suite, native SQLite/provider mocks, onboarding and Features
checks, plus Chromium checks of the real renderer with synthetic IPC: dialog
focus and dismissal persistence, the Accounts reminder, independent preferences,
mouse/keyboard sorting, aligned columns, narrow scrolling and both densities.
See the [sorting evidence](https://github.com/Coke1120/Morrow-Mail/blob/v0.3.18/docs/testing/mail-columns/README.md).

These checks do not establish packaged macOS/Windows interaction, native file
picker behavior, live Google setup/consent, assistive-technology behavior or
real-mailbox performance. No real mailbox or account action was used for validation.
Native updater end-to-end transitions remain unverified.

Release builds use standard GitHub-hosted Windows x64 and macOS ARM64 runners.
Windows remains unsigned. macOS remains ad hoc signed, without Developer ID
signing or notarization; the Ed25519 manifest authenticates the download but does
not grant Gatekeeper trust. See [packaging and updater limits](https://github.com/Coke1120/Morrow-Mail/blob/v0.3.18/docs/PACKAGING.md).
