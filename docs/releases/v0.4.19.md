# Mail, updates, and recovery fixes

- [#612](https://github.com/Coke1120/Morrow-Mail/pull/612) improves mailing-list unsubscribe handling, retains unsubscribe details during partial sync, and preserves line breaks and table-cell spacing in outgoing plain-text mail.
- [#613](https://github.com/Coke1120/Morrow-Mail/pull/613) prevents duplicate sends when a local automation request is retried and improves local MCP error reporting.
- [#614](https://github.com/Coke1120/Morrow-Mail/pull/614) rechecks mailbox transfers before sending and keeps retry and recovery options available when the provider confirms a failure.
- [#615](https://github.com/Coke1120/Morrow-Mail/pull/615) ties update installation to an approved quit and keeps notifications and scheduled digests working if the app stays open. [#619](https://github.com/Coke1120/Morrow-Mail/pull/619) makes the Windows batch test wait for dispatch.
- [#616](https://github.com/Coke1120/Morrow-Mail/pull/616), [#617](https://github.com/Coke1120/Morrow-Mail/pull/617), and [#618](https://github.com/Coke1120/Morrow-Mail/pull/618) restore usable window positions after display changes, preserve MBOX import progress and allow failed removals to be retried, and cancel queued attachment downloads and saves promptly.

Native installer launches, system notifications after an interrupted update, and live mailbox accounts were outside the regression test scope.
