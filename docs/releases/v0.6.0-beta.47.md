# Morrow Mail 0.6.0-beta.47

This beta makes the native Inbox easier to scan and identifies each message's owning mailbox in combined views.

## Changes

- macOS and Windows place the local date/time at the right of each sender header.
- All accounts and search results show the owning mailbox beside the sender. Long names and addresses truncate, with full mailbox/date values retained in tooltips and accessibility.
- Unread sender names and subjects stay emphasized while preview text uses regular weight. Read, Reply All and Trash shortcuts share the subject line, so the date and sender header remain stable on hover or focus.
- Windows uses an accessible Delete icon and tighter toolbar spacing to prevent Delete and Refresh from overlapping at the minimum list width.

## Validation and limits

Fresh tagged macOS and Windows builds, Node-free Rust formatting, strict all-target Clippy and locked tests, full macOS production-service acceptance, the Windows fresh/owned/restart UI walkthrough and fictional-mail benchmark must pass before either download is public. The existing publisher verifies same-run/same-attempt platform artifacts and signs the update manifest against the pinned public key. No test waiver applies.

Native list checks cover 260/320/500-point widths and all three densities. Windows additionally exercises Light/Dark themes, visible non-overlapping header and toolbar controls, accessible account/action names and stable date placement when quick actions appear. Native fixture screenshots are retained in CI evidence. Source-candidate visual checks confirmed the narrow Windows toolbar correction; tagged CI and public-download verification are recorded in VERIFICATION.md. Account identity, owner-bound operations, persisted data and reader security behavior are unchanged.

Checks use fictional mail/providers and isolated temporary workspaces. No real mail, calendar event or paid-model request is submitted. The local Parallels/Windows ARM manual walkthrough remains incomplete; Windows evidence comes from hosted x64 native checks. Full attachments, continuous provider delta/deletion sync, full live-account/provider/model, real external HTTPS image fetching, physical-pointer/accessibility, clean-machine and complete installed-updater restart/rollback acceptance remain incomplete. The previously recorded intermittent Windows reader initialization timeout remains unresolved. macOS is ad-hoc signed without notarization; Windows is unsigned. This is an experimental prerelease.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. Keep the separate mailbox workspace backed up and run one client against it.
