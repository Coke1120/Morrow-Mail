## Undo confirmation and Details focus

Undo all and Undo selected show the reviewed change count and action breakdown
before restoring completed Archive, Trash or Move operations. The notice's
read-state Undo also asks for confirmation. Cancel or Escape makes no mailbox
changes and preserves the checklist. New completions are excluded from an open
confirmation; expired or retired offers require a new review. Duplicate clicks
cannot start duplicate prompts or restores while the request is pending.

Select all and Clear selection keep Details open across native mouse and keyboard
focus changes. Clear only unchecks rows. Outside clicks and Tab-away still dismiss
the panel. Existing restore settlement, reader ownership and separate Outbox
Undo-send behavior are preserved.

## First-use Google setup after startup dialogs

On a fresh profile without accounts or a configured Google client, setup waits
for What's New or another open dialog to close, then checks current account and
client readiness before appearing. Slow changelog reads preserve this order;
closing a dialog no longer loses the pending offer until the next launch.
Readiness reads are serialized, and stale responses cannot stack a setup prompt
over a newer dialog or a newly configured profile.

Later, Escape, successful import and dismissal in another window still end the
offer. Import remains explicit and does not start Google authorization or prove
Cloud setup or consent is complete. Existing profiles and installations with a
bundled, imported or environment client retain their existing setup path.

## Validation and distribution

This version combines [#453](https://github.com/Coke1120/Morrow-Mail/pull/453) and
[#454](https://github.com/Coke1120/Morrow-Mail/pull/454). Their combined source passed
the full offline check suite and Chromium checks with production HTML/CSS/handlers
and synthetic IPC. Undo coverage includes native pointer/keyboard focus,
confirmation cancellation, frozen and stale operation IDs, delayed once-only
restores, nested dialogs, outside dismissal and read-offer expiry. Startup coverage
runs unmodified boot through What's New OK/Close/Escape, a single focused setup
dialog, Later/Escape persistence across reload, intervening Settings, newly
configured suppression and rendered Features help.

No real mailbox, credentials, provider writes or Google consent were used for
validation. Native macOS/Windows installed-app interactions, OS file pickers and
updater end-to-end transitions remain unverified.

Release builds use standard GitHub-hosted Windows x64 and macOS ARM64 runners.
Windows remains unsigned. macOS remains ad hoc signed, without Developer ID
signing or notarization. The authenticated update manifest does not grant
Gatekeeper trust. See [packaging and updater limits](https://github.com/Coke1120/Morrow-Mail/blob/v0.3.19/docs/PACKAGING.md).
