## Signatures by identity

Compose Signatures is one Settings entry. The dialog lists Account default and
each send-as or domain on the left, and edits that identity's signature on the
right. An optional Edit signature link still opens the same dialog for the
active From.

## Status chip and Undo Details

The status chip and Undo Details keep the active session while restores finish,
preserve scheduled-restore feedback, and keep focus and selection stable when
the offer changes.

## Outbox Undo and Outlook Calendar

Outbox Undo resumes a draft with its validated Agent todo intact. Outlook
Calendar description compares use trimmed text on both sides; revision and
if-match stay as before.
