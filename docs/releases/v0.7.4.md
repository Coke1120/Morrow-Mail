# Morrow Mail 0.7.4

This release improves bounded mailbox synchronization and reduces repeated
database/full-text work. Unchanged messages skip writes; read/star/folder metadata
can update without reindexing the full body. Actual searchable content changes
still refresh the index.

Gmail now persists history and crash-safe page/change checkpoints, resolving
new mail, labels and deletions and recovering expired cursors within reviewed
coverage. IMAP tracks new UIDs by connection/folder/UIDVALIDITY and uses
capability-gated CONDSTORE/QRESYNC for bounded cached flags/deletions, with polling
fallback. Outlook retains its existing delta worker while avoiding overlapping
rolling reads and allowing healthy folders to progress past blocked checkpoints.

Mutable drafts still refetch. Reviewed sent content, owner-bound attachment
bytes, current-page priority TTL, background quotas and user-controlled intervals
remain protected. See [synthetic measurements and bounds](../SYNC_PERFORMANCE.md).
Backend timings do not establish a native UI or real-account latency gain.

Publication requires both platforms to pass the existing tagged native checks
and the same-run/same-attempt pinned-key publisher. macOS remains ad-hoc signed
without Developer ID notarization; Windows remains unsigned. Live-account,
clean-machine, full manual accessibility and Mac mini Parallels acceptance remain
incomplete. Pre-existing Windows first-acquire error 87/unknown exits and
intermittent reader timeouts are not declared repaired. Reader/process/security
gates, TLS checks and update-signing keys were not weakened or changed.
