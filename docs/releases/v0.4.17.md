# Outbox recovery, Agent actions, Calendar and Case Timeline

- [#598](https://github.com/Coke1120/Morrow-Mail/pull/598) preserves the message body when an Outbox send fails before delivery. Check Drafts if the compose window cannot reopen, or Scheduled mail if saving the draft failed. Agent offers Undo for confirmed read-state changes and displays “Not attempted” for skipped batch items.
- [#599](https://github.com/Coke1120/Morrow-Mail/pull/599) preserves the original timestamp at the other end of a calendar event when you edit only its start or end time.
- [#597](https://github.com/Coke1120/Morrow-Mail/pull/597) checks that a Case Timeline selection leaves room for its overview before starting the AI requests.
