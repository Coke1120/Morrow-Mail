## Mail layouts, columns and status

View offers Right, Bottom and Separate window reading layouts. Mail list corners
and Sync menu layering stay consistent across layouts. Columns controls which
mail fields are visible, including available reply/forward status. Provider status
reflects supported downloaded metadata; it is not a complete history of actions
performed outside Morrow. Outbox rows display recipients correctly. Keyboard
header moves retain hidden columns in the complete saved order.

## On-demand message Summary

The reader toolbar can summarize the downloaded message using the configured AI
and existing AI data permission. It does not fetch missing message content or
summarize automatically. Cancel and retry remain request-scoped, and incomplete
or truncated content is identified. AI output needs checking against the source.

## Separate window keyboard shortcuts

Delete/Backspace and R/A/F follow exactly one visible selected message and its
account in the Separate window shell. Independent readers keep their own message.
Right/Bottom preview shortcuts pause while opening or after a failed open. Empty
or multiple selections cannot act on an old hidden preview. A reply already
requested retains its captured message/account if the selection changes.

Notification clicks open an independent reader when Separate window is selected;
they do not open or mark mail read through the hidden shell preview.

## Validation and rollout limits

Automated regression suites use synthetic accounts, messages, AI responses and
provider operations. Browser checks exercise the combined reading layouts,
keyboard targeting, Summary cancellation/retry and scoped accessibility states.
Release publication requires Ubuntu/Windows CI, both packaged platform builds,
macOS strict bundle and extracted-ZIP integrity, paired provenance, feed hashes
and the macOS Ed25519 manifest.

Live provider behavior, real AI output and installed Windows/macOS updater
transitions have not been exercised for this release. Native notification
permissions, delivery and OS scrollbar preferences retain their existing smoke-test
limits. Windows is unsigned; macOS is ad hoc signed without Developer ID or
notarization. Existing manual bridge installation requirements still apply.
