# Morrow Mail 0.6.0-beta.43

This beta includes the merged mail refresh, AI summary diagnostics and Windows reader fixes from PR #17 and PR #18.

## Changes

- Outlook and IMAP All Mail refresh downloads bounded Inbox and Sent pages even when the inactive individual-folder checkboxes are off. Selected-folder imports keep their reviewed scopes.
- Reimported Outlook messages update downloaded provider-folder membership while preserving local IDs, local markers and account ownership.
- Automatic mail refresh remains due while another operation holds the mailbox lock, allowing the next worker tick to try again. An actual attempt, including a failed read, retains the normal interval.
- Failed manual, scheduled and arrival AI summaries retain safe model connection, HTTP, timeout and response-format diagnostics in their saved reports. Raw provider responses stay excluded. Historical generic errors cannot recover their discarded cause, and failed paid requests are not automatically retried.
- Windows keeps the reader aligned with the actual selected message when returning to an already displayed row while another detail read is pending, including selection changes during marker updates. Explicit Read/Unread choices survive recovery, another message is not accidentally marked read, and returning from multi-selection to the same message retains its Hide external images choice.

The default-off external HTTPS image setting, individual Hide/Load controls, native reader isolation and pinned update signing key remain unchanged.

## Validation and limits

The existing paired workflow requires fresh tagged macOS and Windows builds, Node-free Rust formatting, strict all-target Clippy and locked tests, full macOS production-service acceptance, the Windows fresh/owned/restart UI walkthrough and fictional-mail benchmark before either download becomes public. The existing publisher verifies same-run/same-attempt platform artifacts and signs the update manifest against the pinned public key. No test waiver applies.

Regressions cover All Mail and selected-folder refresh, provider-folder membership and local markers across colliding account IDs, busy-mailbox scheduling, safe summary diagnostics and restart persistence, plus actual Windows selection events with Read/Unread/Starred/Pending updates and retained image consent. Tagged CI and public-download verification are recorded in VERIFICATION.md.

Checks use fictional mail/providers and isolated temporary workspaces. No real mail, calendar event or paid-model request is submitted. Full live-account/provider/model, real external HTTPS image fetching, physical-pointer/accessibility, clean-machine and complete installed-updater restart/rollback acceptance remain incomplete. Bounded refresh is not a complete provider mirror. The previously recorded intermittent Windows reader initialization timeout remains unresolved. macOS is ad-hoc signed without notarization; Windows is unsigned. This is an experimental prerelease.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. Keep the separate mailbox workspace backed up and run one client against it.
