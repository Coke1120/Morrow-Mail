# Clearer mail dates, reply quotes and AI settings

- [#572](https://github.com/Coke1120/Morrow-Mail/pull/572): The Date column uses
  Today and Yesterday for the device’s local calendar days, refreshing at
  midnight and when the app regains focus. Older dates, exact timestamp
  tooltips, sorting and Outbox behavior are unchanged.
- [#573](https://github.com/Coke1120/Morrow-Mail/pull/573): In fresh Reply and
  Reply All, editable HTML quotes use the read-only preview’s layout defaults
  for tables, images and whitespace. The editor still owns the outgoing
  message; plain-text fallback and remote-resource blocking are unchanged.
- [#573](https://github.com/Coke1120/Morrow-Mail/pull/573): Settings → AI
  shows the saved permission status by default. Manage permissions opens the
  explicit manual choice, with Timeline, Case and background choices under
  Optional access. Existing grants, saved connection checks and AI Setup
  behavior are unchanged.
