## Settings, Timeline and mail indicators

This release brings together the reviewed Settings, Timeline, Sidebar,
Onboarding and Gmail reply/forward changes.

- Compose settings explain mailbox defaults and Preferred From with question-mark
  help. Refresh From addresses sits beside Sender identities and preserves local
  names and aliases. AI privacy details open separately from the compact controls.
- Timeline revalidates its source snapshot during routine account notifications.
  Correspondence appears oldest first, grouped by day, with undated mail last and
  expandable evidence. Reviewed HTML export is responsive, printable and inert;
  JSON schema 1.0.0, Markdown and isolated PDF remain available.
- Scheduled and Out of Office share one sidebar row and open separate dialogs.
  Each account, including Yahoo and custom IMAP, has an independent saved expansion
  choice. Folder filtering temporarily reveals matches; Collapse All preserves
  account choices.
- The final setup-guide step offers Undo send, default schedule delay and remote
  image preferences. Each setting needs an explicit Save. Keep current, Skip,
  Back and Finish do not silently enable remote images or change saved preferences.
- Gmail records reply/forward evidence after complete confirmed submission.
  Confirmed evidence survives sync, label-copy replacement and missing or malformed
  RFC Message-ID headers by using the original provider identity. Provider booleans
  remain authoritative. Historical reply inference uses only already-downloaded
  Sent mail with an exact, unique parent relationship; ambiguous records and Gmail
  reactions stay unknown. Cross-device forwarded state remains unavailable.
  No extra mailbox scan, provider label write or OAuth scope is introduced.

### AI permission renewal

Consent disclosure version 3 names Timeline's sender names/addresses, mail dates
and their provenance, and optional keyword/contact focus alongside reviewed text,
subjects and attachment names. Previous AI grants require renewed manual approval
in Settings → AI. Reading the status or saving a connection grants nothing.
Background use remains off unless separately chosen. Only an explicit Generate
starts Timeline AI work, after source and coverage review. Export still needs a
fresh personal-information review and a native file selection.

### Validation and distribution

The five-feature tree passed synthetic host, SQLite, renderer and Chromium
integration checks, including the valid-v2-consent renewal boundary and the
missing/malformed Message-ID persistence regressions. Its release source must
also pass exact-source Linux/Windows CI and the normal paired Windows x64/macOS
ARM64 build before publication. Signing roots, credentials and workflows are
unchanged. Both platforms' staged provenance, update feeds and hashes must agree
on version and source; the publisher verifies uploaded bytes before promotion.

Windows remains unsigned. macOS uses ad hoc signing and an authenticated update
manifest, without Developer ID signing or notarization. Build/archive integrity
checks do not establish native GUI, live mail/AI/provider authorization, real PDF
rendering or installed-updater end-to-end coverage. Native Electron navigation
could not be verified in the test environment; browser and mocked PDF checks
passed. The existing macOS manual-bridge and destination-policy limits remain.
