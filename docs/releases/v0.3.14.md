## Hermes Agent and opt-in cached-mail notifications

Bot mail can use Hermes Agent. Cached-mail notifications stay opt-in.

## Proactive halt, thin listener-status, and hidden schedule validation

Proactive bot work stops cleanly when a cursor or status write fails.
Listener status lives in a thin module so the scheduler does not pull Agent
send paths. Hidden interval and cron inputs stay disabled so native form
validation ignores inactive schedule controls.

## Bulk Undo epoch-gate and overnight scan cursor retain

Bulk Undo keeps the reader clear across epochs. Overnight scan keeps its
cursor on the retain path.

## Not in this version

The Electron/Node security bump is not in this version.
