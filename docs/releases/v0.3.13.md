## Sponsor links in Features and Settings

Features and Settings Support include GitHub Sponsors and Buy Me a Coffee
links. Sponsor destinations in Features are clickable.

## Undo, signature, Outbox, overnight, and Learned recoveries

Undo, signature loading, Outbox, and overnight scan stay bounded. Learned
recoveries after a read failure no longer stick on a stale error. The Learned
stamp and Features sponsor link wiring keep working when helper stubs lack
DOM query methods.

## Not in this version

The Electron/Node security bump is not in this version.
