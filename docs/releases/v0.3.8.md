## Unread filter

Opening an unread message in the sidebar Unread filter, or in the All Account
Mail Unread chip, may mark it read and keeps that one row until you open a
different unread message. Opening a message that is already read, opening the
held row again, or highlighting a row without opening it does not start a new
hold. Mark read on the held row from the row button leaves it listed. Mark
unread clears the hold. Mark read on a row that is not held removes it.
Multi-select Mark read removes every selected row, including the held row when
it is selected. Leaving Unread, switching folder or account, searching, or
turning the filter off clears the hold. Coming back does not restore it.
Refresh and Sync keep the held row unless the message is gone. Other filters
do not keep a read row this way.

## Compose recipients

To, Cc, and Bcc suggest up to eight addresses already in synced mail on this
computer, ranked by how recent and how often they appear. Arrow keys then
Enter, or a click, inserts one. Enter without a highlighted suggestion still
previews the send, and an address you type is kept. Suggestions do not read a
contacts directory or add a provider scope.

## Agent todos and batch read

A successful Reply or Reply All completes only the Needs You todo recorded
when that reply starts. Forward, a new message, a saved draft, a canceled
compose, a failed send, and a queued or scheduled send leave that todo open
until the send succeeds. Mark as read leaves it open. The Settings opt-in
"Mark as read also completes Agent todos" is off by default. Mark read & done
marks the message read and completes the todo. FYI and Other offer Mark
category as read for the messages listed there, with Undo, and do not complete
todos. Needs You has no Mark-all. Select rows, then Mark selected as read or
Complete selected. The label says all only after every listed row is selected.
Done and Dismiss stay on this computer.

## Not in this version

Agent learning from corrections, the Agent card view, nesting Outbox under a
collapsible All Account Mail, and the Electron/Node security bump are not in
this version.
