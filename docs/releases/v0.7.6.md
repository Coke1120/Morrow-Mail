# Morrow Mail 0.7.6

This release includes [PR #32](https://github.com/Coke1120/Morrow-Mail/pull/32):
Today and Reply suggestions share account tabs, compact review queues, inline
original messages and editable account-owned replies. All accounts is a read-only
aggregate. Account-owned drafts and explicit sending review retain their owner.
Review preserves edits, selection, scroll and unsaved budgets across account
switches and errors, and uses a single pane in narrow content. Updated evidence
withdraws old facts approval; users can retain edits while refreshing the source
and recipients. Unanswered decision placeholders cannot enter sending review.

Downloaded conversations use account-scoped provider IDs, RFC references and
verified local replies. Later mail, actual outgoing mail, source edits and
deletions withdraw stale and in-flight proposals. Opening mail or saving a draft
does not complete an event. Missing, truncated, withheld or unconfirmed context
remains uncertain. Deadlines retain their original wording.

[PR #33](https://github.com/Coke1120/Morrow-Mail/pull/33) also reduces the Windows
observer's first-open window by pinning current children of verified live parents
before earlier siblings' managed admission. Original handles retain exact
identity and zero/nonzero exit evidence; provisional pins grant no counters,
cache identity or descendant authority. First-acquire failures, unknown/nonzero
exits, identity/parent/counter errors and existing deadlines remain strict gaps.
This removes sibling-admission delay, not all possible pre-pin disappearance or
complete process-lifetime coverage. See [the contract and controls](https://github.com/Coke1120/Morrow-Mail/blob/v0.7.6/docs/WINDOWS_EARLY_ADMISSION_PINS.md).

## Distribution and coverage limits

macOS is ad-hoc signed without Developer ID notarization. Windows is unsigned.
Manual VoiceOver/Narrator, keyboard/focus/large-text, clean-machine, installed-app
and real-account/model/provider acceptance remain incomplete. Historical
intermittent reader timeouts and pre-pin Windows observation failures remain
historical failures; successful new samples do not certify them repaired.

Review uses bounded downloaded mail: at most 10,000 recent source/removal metadata
records, 10 permitted model-context messages, 200 reply candidates and 20 saved
summary jobs as Today event entry points. This is not a complete provider mirror
or semantic model-quality certification. Unsaved state survives account/page
changes within the current session; Save draft provides restart persistence.
Mail is never sent automatically. See [review behavior and bounds](https://github.com/Coke1120/Morrow-Mail/blob/v0.7.6/docs/REVIEW_WORKSPACE.md).

Only fictional temporary workspaces were used. This task did not access real
mail databases, change credentials or include separate Thunderbird sync work.
