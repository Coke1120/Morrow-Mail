## Mail review, Brain refresh and reading fixes

This release contains the reviewed #507–#518 batch.

- Feature reads recover from expired authorization and temporary Google-client
  configuration errors while preserving separate mail, Calendar and Graph grants.
- Summary shows one main point and up to six flat, plain-language bullets.
  Longer or incomplete downloaded content needs an explicit full-text or excerpt
  choice. Full runs remain bounded, preserve Unicode and disclose incomplete
  coverage. Summary uses this message's downloaded text and quoted history;
  attachment files, linked pages, other mail and Brain history are excluded.
- Timeline includes the complete reviewed request in its preflight budget,
  reduces long-message summaries in bounded stages and reports attempted AI
  request counts after failure. Explicit Retry revalidates the same source and
  sends the reviewed mail again. Cancellation cannot recall delivered data.
- To Me matches the owning mailbox's primary address in the cached To header,
  before paging and search limits. Cc/Bcc-only mail, aliases, plus variants and
  delivery headers do not match. It keeps the other list filters and excludes
  Outbox.
- Attachments start collapsed. The heading keeps the count and Save as ZIP
  visible; keyboard expansion retains each file's Preview, Save and Open actions.
  Collapse does not cancel transfers. All Mail, Inbox and Sent chips share the
  same left edge and wrap within narrow lists.
- Main-window Delete/Backspace and reader Delete use the reviewed multi-selection,
  including selected messages hidden by a filter. With no selection, preview
  Delete uses the open message; Separate window needs a selection. Independent
  readers keep their own message target and existing confirmation remains.
- Preview Send and Outbox show safe readable HTML through the existing sanitizer
  and remote-image policy. Recipient, subject and sending review remain intact.
  Fresh Reply/Reply All and Forward normalize recognized Chinese/Japanese,
  AW:/WG: and numeric prefixes while retaining Unicode and mixed action history.
  Edited subjects, resumed drafts and recovered scheduled mail keep saved text.
- Gmail can repair eligible cached historical Reply evidence within the ordinary
  bounded sync budget. Headerless originals use provider identity; incomplete
  MIME trees and ambiguous relationships cannot establish a reply.
- IMAP records local Reply/Forward evidence only after every intended To/Cc/Bcc
  recipient is confirmed accepted, then attempts supported server flags with
  account, endpoint, UIDVALIDITY and UID checks. Unsupported writes retain local
  evidence; marker failures cannot replay an accepted send. Legacy provider
  indicators survive the cache upgrade. Device-local evidence does not sync:
  cross-device markers require server persistence and client support. A crash or
  storage failure after acceptance but before optional evidence can omit a marker.
- Settings → Brain offers Daily (default), Weekly and Manual only. Timer and
  page-open checks share one queued/running job and the 24-hour/seven-day interval.
  Failed automatic attempts wait that interval across restart. Manual Refresh or
  Rebuild can retry. Scheduling runs only while Morrow is running; changing cadence
  never grants AI permission, and queued work rechecks the saved destination and
  consent. Background AI data use remains a separate opt-in in Settings → AI.
- Charset parsing handles quoted and continued MIME parameters. Decoding loss,
  unknown encodings and older-cache uncertainty appear separately from download
  failures. Original HTML stays cached; checked plain text can provide a safer
  readable alternative, with an explicit choice for ambiguous body sections.
  Only explicit Retry download replaces complete server copies. Pending local
  edits remain protected, and unusable partial copies cannot replace complete
  bodies. Retry cannot reconstruct sender/provider-lost bytes or silently guess
  another charset.

### Validation and distribution

All twelve exact feature heads passed Linux and Windows CI, and each cumulative
tree passed the full local checks. Synthetic host, real SQLite/MIME-parser,
renderer and Chromium checks cover consent, credential/identity races, confirmed
delivery, drafts/queues, coverage limits and the combined layouts/Features help.
The legacy IMAP checkpoint regression fails before its correction and passes
afterward; all 29 IMAP cases pass. Brain has 10 lifecycle/consent cases and three
subject-preservation cases. Chip alignment has 18 comparisons across widths and
themes, narrow wrapping and keyboard/axe checks.

The final versioned source must also pass exact-source CI and the normal paired
Windows x64/macOS ARM64 build before publication. Release roots, credentials and
workflows remain unchanged. Provenance, feeds, source SHA, version and asset hashes
must agree; the publisher verifies uploaded bytes before promoting its draft.

Windows remains unsigned. macOS uses ad hoc signing and an authenticated update
manifest without Developer ID signing or notarization. Native windows,
screen-reader acceptance, sleep/wake, real credentials, live mail/AI/provider
policies and installed-updater end-to-end behavior remain unverified. Existing
macOS manual-bridge and destination-policy limits still apply.
