## Compose settings

Settings → Compose opens on display names, Preferred From, and a Signatures
shortcut. Domain CC/BCC, aliases, the alias mailbox, and the fallback CC domain
stay in Advanced. Advanced stays collapsed until a saved CC rule, BCC rule,
alias, or fallback domain exists. Preferred From and display-name overrides do
not open it. The longer policy notes sit in How this works. The existing rules
and their storage are unchanged.

## From across mailboxes

Compose From lists authorized addresses for every connected mailbox, grouped by
account. Reply and forward still start on the mailbox that received the
message. Choosing an address the current mailbox does not authorize switches to
that mailbox and reloads its send-as list, CC/BCC defaults, and signature
domain. Draft save and send use the selected mailbox. The previous mailbox's
draft is left in place. If the reloaded context does not authorize the chosen
address, the switch is discarded and the original mailbox stays selected. The
same address on two mailboxes stays with the current mailbox.

Bot mail.send still sends only for the granted account and an address that
account authorizes.
