# Roomier replies and clearer Google Groups actions

- [#586](https://github.com/Coke1120/Morrow-Mail/pull/586): Compose fits the opener's display and uses more room for the draft. On narrow windows the separate original-message preview stays compact. Send, Save draft and Close stay outside the scrolling area. Reply recipients, quoted content and draft behavior are unchanged.
- [#585](https://github.com/Coke1120/Morrow-Mail/pull/585): Google Groups leave actions move from the unsubscribe banner to the message actions menu as **Leave Google Group…**. Review the draft and decide whether to send it; sending can stop future mail from the entire group. Ordinary unsubscribe options are unchanged.
- [#587](https://github.com/Coke1120/Morrow-Mail/pull/587): Contributor documentation only; no app behavior change.

The compose changes have automated regression checks. Native Electron visual checks, including very compact windows, were not run. Windows x64 builds are unsigned. The macOS arm64 archive uses ad hoc signing and an authenticated updater manifest; it is not notarized. Older macOS builds that require the previous versioned ZIP filename may need a manual update.
