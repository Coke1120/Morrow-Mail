# Morrow Mail 0.6.0-beta.38

This beta connects Today, Ask and the reply queue to owned source mail and reviewed drafts, adds manually reviewed local Inbox rules and Later, and improves native inbox selection and model connection feedback.

## Changes

- Show validated Today reply previews and source links from summaries, Ask and the reply queue. macOS opens a reviewed draft directly; Windows opens the owning review queue. Source lists describe permitted context, not verified model conclusions.
- Offer optional Ask retrieval from an already approved Smart Search index, with embedding-cost disclosure. Keyword retrieval remains the default; Ask never starts indexing. Treat questions containing colons, quotes or operator-looking text as literal questions while preserving the normal Search grammar and input limits.
- Keep the macOS source reader selected after leaving Today, Ask or the reply queue, including sources outside the first mailbox page and duplicate provider IDs across accounts.
- Separate Brain business facts, writing voice and reviewed guardrails under their existing permissions.
- Add saved local Inbox rules for exact sender/domain or subject text. Every manual apply requires a new, single-use ten-minute preview of the newest 500 downloaded Inbox rows. Up to 30 rules per account may apply local Star, Pending or Later; they never run automatically or perform provider moves.
- Add a persistent Later view independent of Pending and stars. Inbox/Archive messages retain their provider folder, and imports/restarts retain the local marker. Both clients expose Later and account-owned navigation.
- Support native multiple selection with Command/Ctrl and Shift gestures, owned batch local actions, reviewed sequential provider Trash moves and batch Undo. Preserve each deletion's account-bound one-minute token; stop on failure without automatic replay. Arbitrary bulk destination moves and permanent deletion remain unsupported.
- Keep an opened, newly read message at its original Unread list position until another message, view or page opens. Retain manual read/star/Pending changes and use the server's unread count.
- Track AI activity for shared model work and expose safe connection, HTTP, response and timeout diagnostics. Closing one waiter does not interrupt still-running shared work; the 45-second timeout and explicit retry remain.
- Preserve saved chat/embedding keys across equivalent validated endpoint spellings and model changes. Native settings collapse replacement controls; Windows retains an entered key after rejected connection tests or failed saves.

The public AI Emaily comparison in `docs/AI_EMAILY_REVIEW-2026-10-03.md` explains the adopted workflow ideas and limits; it does not claim authenticated competitor testing.

## Validation and limits

The existing paired workflow must pass both platforms' Node-free Rust formatting, strict all-target Clippy and locked tests, native builds/acceptance, Windows fresh/owned/restart walkthrough and fictional-mail benchmark before either download is published. The publisher requires same-run/same-attempt provenance and signed update manifests against the unchanged pinned key. No waiver applies.

Regression fixtures cover literal Ask syntax/length, owned duplicate IDs, permissions and revocation, source references, rule review/reconnect invalidation, Later persistence, native source navigation, multiple selection and Unread retention. They use isolated fictional workspaces and loopback model fixtures; no real mail, calendar event or paid-model request is submitted. Installed apps are not replaced.

Live-account batch Trash/Undo, complete provider/model acceptance, physical-pointer/accessibility checks, clean-machine acceptance and installed-updater restart/rollback remain outstanding. The intermittent Windows reader initialization timeout remains unresolved and its security gate is unchanged. The earlier Parallels walkthrough covers beta.30.

macOS is ad-hoc signed without notarization; Windows is unsigned. This is an experimental prerelease with incomplete live-account acceptance. Tagged CI and public-download verification are recorded in VERIFICATION.md.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. Older macOS versions predating beta.30 may still require one manual Quit during upgrade. Keep the separate mailbox workspace backed up and run one client against it.
