## Compact Local Folders actions

This patch release contains [#530](https://github.com/Coke1120/Morrow-Mail/pull/530)
and versioned release notes. Local Folders now has compact plus (**New local
folder**) and **Import MBOX** icon buttons beside its account-list heading,
replacing the two full-width text actions.

The buttons retain accessible names, native tooltips, dialog semantics and visible
keyboard focus. They remain separate from expand/collapse and stay available when
folders are collapsed. Existing reviewed folder creation and MBOX import handlers
are unchanged. Opening an action does not create a folder, pick source files or
start an import. Cancellation and import-trigger focus restoration remain covered.
Features and help describe the entry points; MBOX documentation now correctly
identifies its availability since v0.4.3.

### Validation and distribution

The icon change passed the full local synthetic check, 15 focused Local Folders,
MBOX, folder-chip and sidebar tests, and exact-head Linux and Windows CI. Chromium
with synthetic IPC and a temporary SQLite archive exercised Enter/Space/Tab/Escape,
reviewed creation, cancellation, independent collapse and replacement-trigger focus
restoration. Eight light/dark layouts at 1280, 900, 760 and 390 px had visible
keyboard focus and no sidebar horizontal overflow. Supplemental Electron UI
fixtures could not complete in the headless environment. Native Windows/macOS
pickers, assistive technology and real mail were not exercised.

The final versioned source must pass the full synthetic check and exact-main Linux
and Windows CI before release. The normal paired release workflow must validate
Windows x64 and macOS ARM64 packaging, source/run provenance, updater feeds,
checksums, extracted macOS bundle integrity and the Ed25519 update manifest before
publication. Existing signing roots, credentials and release workflows are unchanged.

Windows remains unsigned. macOS is ad hoc signed, without Developer ID signing or
notarization. Ed25519 authenticates the release download but does not grant macOS
execution permission. Live providers/AI and installed-updater transitions remain
unverified. Existing manual-bridge and destination-policy limits still apply.
See [v0.4.3](v0.4.3.md) for Local Folders, MBOX import and Case Timeline limits and
privacy disclosures.
