# Agent decisions, batch actions and safety review

- [#580](https://github.com/Coke1120/Morrow-Mail/pull/580): Agent → Todos shows pending decisions with their reason, mailbox and separate read status. It shows a deadline only when the subject identifies an explicit ISO date as a deadline. Recognized this time applies to the exact item in the current window; Not me keeps it unresolved.
- [#578](https://github.com/Coke1120/Morrow-Mail/pull/578) and [#580](https://github.com/Coke1120/Morrow-Mail/pull/580): Select messages across mailboxes and mark them read without completing their todos. Archive requires a review of exactly the selected messages, not full conversations. Receipts distinguish successful, pending, failed, unknown and unattempted actions; Undo is offered only for confirmed reversible changes.
- [#577](https://github.com/Coke1120/Morrow-Mail/pull/577): The Agent safety review groups cached messages by priority and previews proposed rules without saving or running them.
- [#576](https://github.com/Coke1120/Morrow-Mail/pull/576): The local MCP adapter can mark read or archive up to 10 specified messages in one previously authorized mailbox, with per-message results. It stops on an unknown outcome rather than retrying automatically.

No new mailbox permissions, automatic archiving, or long-term rules are enabled.
