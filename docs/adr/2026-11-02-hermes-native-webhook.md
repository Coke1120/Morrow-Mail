# Native Hermes outbound webhook authentication

Morrow's proactive sender previously used an optional Bearer credential for both bot platform labels. Hermes' native webhook verifies HMAC signatures, so changing the platform label or pasting its URL did not make that path compatible.

Add an explicit `webhookMode` (`bearer` or `hermes_hmac_v2`) to desktop proactive settings. Missing mode retains Bearer semantics, stored shape and cursor/delivery identity. A new Hermes editor suggests HMAC without saving or authorizing it. A mode change is a reviewed destination change: retire the old credential and reset the delivery cursor. Blank replacement retains a credential only for the same URL/platform/mode. Secret storage and commit compensation continue through the existing facade; the renderer/status/audit never receive the value.

Use Hermes' generic HMAC V2: UTF-8 secret, Unix-seconds plus a period plus the exact transmitted raw body, SHA-256 lowercase hex, `X-Webhook-Signature-V2` and `X-Webhook-Timestamp`. Reuse the existing stable delivery ID as `X-Request-ID` in addition to `Idempotency-Key`. Retries freeze body/ID but refresh signing time. Existing private DNS pinning, TLS, no redirects, byte/deadline/attempt caps and asynchronous credential revalidation stay in the transport/scheduler. No translation server is added.

Hermes profile selection belongs to the operator's route/profile binding and `/p/<profile>/webhooks/<route>` URL. An output destination such as `deliver: email` does not select an execution profile. Payload stays untrusted mail data and adds no action permission. HTTP 202 admits or buffers work; other 2xx may represent duplicate/filter/direct-delivery paths. Store transport acknowledgement codes and label agent completion unverified, without interpreting response bodies or claiming end-to-end completion.

See [Bot bridge setup and acceptance](../BOT_BRIDGE.md#native-hermes-setup), the [official Hermes guide](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/webhooks) and [source](https://github.com/NousResearch/hermes-agent/blob/d9397d7b559f75e60395af4e5f1a1f593ee8358c/gateway/platforms/webhook.py), checked 2026-11-02. Keep fallback cron until an operator verifies a real authorized push, the execution profile and expected Bot Chat result. This change does not activate Push, change cron, open a port, configure Hermes/Tailscale or repair desktop-control daemon/SDK versions.
