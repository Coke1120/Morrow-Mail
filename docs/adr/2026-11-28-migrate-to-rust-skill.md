# Repository-local `migrate-to-rust` skill

Status: accepted for repository-local reference use. Executing third-party skill scripts or compiling/running cloned external repositories remains gated on explicit confirmation at execution time.

The requested upstream source is [`google/skills`](https://github.com/google/skills/tree/main/skills/developers/migrate-to-rust) (`skills/developers/migrate-to-rust`), pinned to commit `10c799ee69bcdb10b82836403d1531bfcc3d9d24` (metadata version `1.0.0`, Apache-2.0). It is installed under `.agents/skills/migrate-to-rust/` alongside existing repo-local skills. All four upstream skill files (`SKILL.md`, `references/infographic_template.html`, `references/pgo_and_telemetry_guide.md`, `scripts/telemetry.py`) and the root `LICENSE` are preserved unmodified because relative links inside `SKILL.md` and `references/pgo_and_telemetry_guide.md` already resolve cleanly inside the skill folder; `UPSTREAM.json` records their pinned source paths, byte counts, and SHA-256 digests. Adding this ADR brings the change to seven files total (~144 KiB of upstream files plus metadata and ADR), with zero changes to Morrow Mail product source code, dependencies, lockfiles, CI workflows, personal agent settings, or `main`.

## Scoped static inspection

Static checks (without executing third-party code) verified the following:

- **`scripts/telemetry.py`** (1,293 lines, 42,399 bytes): Parsed cleanly with Python `ast.parse`. Uses Python standard-library imports only (`argparse`, `datetime`, `json`, `os`, `pathlib.Path`, `re`, `sys`, `time`), with no third-party dependencies, no `subprocess` or `os.system` launches, no network client imports (`urllib`/`http`/`socket`), and no dynamic evaluation (`eval`/`exec`/`compile`/`__import__`). Filesystem and environment access is bounded to reading/writing `--telemetry` JSON files (`path.parent.mkdir`, `path.open`), scanning source files under the specified target directory (`os.walk`, `read_text`), reading the HTML template (`tpl_path.read_text`), writing the `--out` HTML report (`out_path.parent.mkdir`, `out_path.write_text`), and reading optional `MIGRATE_TO_RUST_MODEL` and `USER` environment variables (`os.environ.get`).
- **`references/infographic_template.html`** (1,332 lines, 63,070 bytes): Contains no external `<script src=...>`, no `fetch`/`XMLHttpRequest`/`WebSocket`, and no `eval` or `new Function`. It references Google Fonts (`https://fonts.googleapis.com` and `https://fonts.gstatic.com`) for `Inter` and `JetBrains Mono` stylesheets and uses an inline `<script>` (plus `localStorage` key `migrate_to_rust_theme` and `history.replaceState`) that interpolates telemetry JSON fields via `.innerHTML`/`.textContent` when opened in a browser, assuming trusted local telemetry inputs.
- This scoped static review is **not** a full security audit or runtime verification.

## Execution gate, precedence, and removal

- **Execution confirmation gate**: Action-time confirmation from the operator is required before running `scripts/telemetry.py` or compiling/executing any cloned external repository (matching the upstream `Stage 0` gate in `SKILL.md` and Morrow Mail's third-party skill policy in `docs/adr/2026-11-03-ui-ux-pro-max-skill.md`). No third-party skill script or external build was run to prepare this installation.
- **Rule precedence**: Morrow Mail's root `AGENTS.md`, repository workflows, and `docs/adr/` decisions always take precedence over guidance or suggestions in `.agents/skills/migrate-to-rust/`. Do not treat catalog links or template directives as permission to fetch remote dependencies, run unconfirmed external builds, or alter repository release/CI rules.
- **Updates and removal**: Updating the skill requires pinning a new upstream commit SHA, re-verifying SHA-256 digests and static boundaries, and updating `UPSTREAM.json` and this ADR. Removing `.agents/skills/migrate-to-rust/` (and this ADR if desired) completely removes the installation because Morrow Mail has zero runtime dependency on it.
