# Mail shortcuts leave Reload and Zoom alone

View → Reload already uses `role: reload` (⌘R / Ctrl+R). Zoom already uses `CommandOrControl+Plus`, `=`, `-`, and `0`.

Reply, Reply all, and Forward are the plain keys R, A, and F while a message is open and focus is outside a field. New Mail is `CommandOrControl+N` on the Mail menu. Settings is `CommandOrControl+,` on the app menu. Send (`CommandOrControl+Enter`) and Save draft (`CommandOrControl+S`) stay in the open composer, so they are not menu accelerators. The Shortcuts rail page, above Debug log, lists the chords with ⌘ on macOS and Ctrl on Windows and Linux.
