# Translate a reviewed Compose selection

A first-party Compose window captures a visible single-paragraph selection from
a fresh draft or reply. The context-menu action captures locally; opening the
review resolves only saved AI configuration. A host review token binds one
Compose window, exact selected text and languages, and the saved AI consent
stamp. Only an explicit Translate action invokes the existing manual consent
lease. The provider receives the frozen passage and language instructions,
not mailbox/recipient metadata, subject, adjacent text, signatures, quoted
history, Brain context or Agent history. A pending request can be aborted, but
text already delivered cannot be recalled.

Preview the immutable original next to an editable output and highlight
unmatched exact times, common currency amounts and alphanumeric references
locally. This is not a check of meaning, localized formatting or translation
quality. Replacing takes a separate explicit decision, validates the saved
connection, frozen draft identity and exact still-connected text range, then
uses Chromium insertText for native Undo. There is no automatic draft save,
send or schedule. Fail closed when verified quote/signature boundaries are not
available, including previously saved/recovered drafts in this first pass.

Native synthetic checks cover the workflow with an in-memory model fixture;
translation quality and paired time savings remain unmeasured (#675).
