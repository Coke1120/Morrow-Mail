        Listener on this computer

        Create an unexpired grant first.

        Same-computer bots can continue using the loopback endpoint with their existing secret, installation ID, and capability marker. No Tailscale host is required for local access.

        Tailscale Serve

        1. On the computer running Morrow, configure Tailscale Serve to forward HTTPS to http://127.0.0.1:47831, with the Morrow app capability. Do not enable Funnel.
        2. Save that computer’s exact Tailscale hostname and port below. Saving only allows that hostname; it does not configure Serve or your tailnet policy.
        3. On your other device, use the HTTPS endpoint below with your private secret file and this installation ID. Local status does not verify the Tailscale connection.

        Saving a host does not install or configure Tailscale Serve.

        Do not enable Funnel. Funnel does not inject the capability marker, and Morrow rejects the call. There is no switch that skips the marker.
