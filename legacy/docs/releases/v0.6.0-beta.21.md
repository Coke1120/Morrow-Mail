# Morrow Mail 0.6.0-beta.21

History import now recovers automatically from temporary provider failures without stopping after three retries or asking you to reconnect or restart the import.

- Network and provider 5xx read failures retry after 30 seconds, 2, 5, 15 and then 60 minutes, continuing hourly while the app is open. Request limits use the existing Sync delays of 1, 2, 5, 15 and then 60 minutes. Daily quota limits wait 24 hours.
- The checkpoint, attempt count and next retry time survive restarts. Switching between temporary error types does not reset the backoff. Settings displays the next retry time and still allows pausing.
- Updating automatically resumes older imports stopped by recognized temporary errors when the original connection is still present. Old quota records wait 24 hours from their failure because they did not distinguish daily limits. Downloaded mail, import bounds and checkpoints are retained.
- Manually paused imports stay paused. Authentication, malformed pages, invalid cursors, changed connections and storage failures retain their explicit recovery controls. Sending, calendar creation and paid AI operations do not gain automatic retries.

## Validation and limitations

Publication requires both existing macOS and Windows jobs to pass formatting, strict Clippy, the locked Rust suite, native packaging and platform acceptance. No test waiver applies. Both platform artifacts and signed provenance must pass the existing publisher before either download becomes public.

Isolated TLS regressions cover more than three alternating failures, hourly and daily cooldowns, process restarts, automatic completion at the saved checkpoint, upgrade recovery, pause/authentication/account safeguards and safe error projection. These fixtures do not establish live-account quota behavior.

macOS is ad-hoc signed without Apple notarization; Windows is unsigned. Clean-machine, complete accessibility/IME/DPI testing and real-provider acceptance remain incomplete. This is an experimental prerelease. Attachments and CID images remain unsupported.

## Install and update

Download the macOS arm64 or Windows x64 ZIP, or use the explicit in-app update flow with its signed manifest. The updater retains the previous app and preserves the separate mailbox workspace. Back up the workspace before updating; do not run two clients against the same workspace simultaneously.

Windows requires a supported Windows 10/11 x64 environment. HTML mail uses WebView2 when available and otherwise falls back to plain text. Both native platforms use the Rust service without a bundled Node runtime.
