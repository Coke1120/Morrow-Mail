# Morrow Mail 0.7.5

This release includes [PR #32](https://github.com/Coke1120/Morrow-Mail/pull/32):
Today and Reply suggestions share account tabs, compact review queues, inline
original messages and editable account-owned replies. `Open source` is now
`View original message`. All accounts is a read-only aggregate; drafts and
sending review retain their original owner and the existing explicit composer.

Today puts decisions and reply shortcuts first, with waiting, completed,
informational items and full summaries folded. Reply review retains edited
text, selection, scroll and unsaved budgets across account switches and errors.
Narrow review content switches to a single list/detail pane. Updated evidence
withdraws old facts approval; users can keep edits while refreshing the original
and recipients. Unanswered decision placeholders cannot enter sending review.

Downloaded conversations use account-scoped provider IDs, RFC references and
verified local reply relationships, never sender or subject alone. Later mail,
actual outgoing mail, source edits and deletions withdraw stale and in-flight
reply proposals. Explicit new requests can reopen closed events. Opening mail
or saving a draft does not complete an event. Missing, truncated, withheld or
unconfirmed context remains uncertain; deadlines retain original wording.

## Distribution and coverage limits

macOS remains ad-hoc signed without Developer ID notarization. Windows remains
unsigned. Manual VoiceOver/Narrator, keyboard/focus/large-text, clean-machine,
installed-app and real-account/model/provider acceptance remain incomplete.
Historical intermittent reader timeouts and Windows first-acquire observation
failures are not declared repaired by a successful new sample.

Review uses bounded downloaded mail: at most 10,000 recent source/removal
metadata records, 10 permitted model-context messages, 200 reply candidates and
20 saved summary jobs as Today event entry points. It is not a complete provider
mirror, and source/format validation does not establish semantic model quality.
Unsaved review state survives account/page changes within the current app
session; use Save draft for restart persistence. Mail is never sent automatically.

See [review behavior and bounds](https://github.com/Coke1120/Morrow-Mail/blob/v0.7.5/docs/REVIEW_WORKSPACE.md).
Only fictional temporary workspaces were used for validation; the release task
did not access real mail, account credentials or the user's database.
