# Morrow Mail 0.6.0-beta.48

This beta adds Sync beside Compose and fixes Outlook messages remaining unread in Morrow after being read on the server, including recently received mail.

## Changes

- macOS and Windows put a labeled Sync button beside Compose in the sidebar. Today offers Sync All; keyboard shortcuts remain available. Manual sync retains the current mailbox, page and selection and prevents overlapping requests.
- Outlook server Read/Unread and star flags replace stale cached flags. Explicit Morrow read/star changes now write back to Outlook with `Mail.ReadWrite`; older read-only connections need reconnecting before those actions can succeed. Mark-on-open skips Outlook accounts without write permission.
- Outlook resumes per-folder incremental change checkpoints across restarts and cycles through older downloaded mail to reconcile flags, moves and server deletions. A permanently deleted server message keeps its cached content in local Trash. Pending, Read Later, local drafts and delivery records are preserved.
- Sync refreshes recent Inbox/Sent mail, one delta page and up to 25 cached messages per cycle. Catch-up continues at the sync interval configured in Settings or with another manual Sync. Historical content imports retain their separate pause and range controls. Failed or unconfirmed flag writes are not automatically replayed; Sync can check the server's current state.

## Validation and limits

Fresh tagged macOS and Windows builds, Node-free Rust formatting, strict all-target Clippy and locked tests, full macOS production-service acceptance, the Windows fresh/owned/restart UI walkthrough and fictional-mail benchmark must pass before either download is public. The existing publisher verifies same-run/same-attempt platform artifacts and signs the update manifest against the pinned public key. No test waiver applies.

TLS-loopback provider fixtures cover recent and older unread mismatches, duplicate IDs across accounts, pagination/restart, moves/deletions, retained cached content, explicit flag writes, permission failures, lost responses, invalid/expired cursors, quota backoff and reconnect races. Native checks cover Sync placement, account scope, retained page/selection, repeated clicks, visible failures and read-only Outlook mark-on-open. Tagged CI and public-download verification are recorded in VERIFICATION.md.

This is bounded polling, not push sync or an immediate complete mailbox mirror. Initial Outlook catch-up can require many cycles. Gmail and IMAP retain bounded polling and local read/star flags; their incremental/deletion synchronization is not included. Checks use fictional mail/providers and isolated temporary workspaces. No real mail, calendar event or paid-model request is submitted. Full live Outlook/provider/model acceptance, full attachments, local Parallels/Windows ARM manual, real external HTTPS image fetching, physical-pointer/accessibility, clean-machine and complete installed-updater restart/rollback acceptance remain incomplete. The previously recorded intermittent Windows reader initialization timeout remains unresolved. macOS is ad-hoc signed without notarization; Windows is unsigned. This is an experimental prerelease.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. Keep the separate mailbox workspace backed up and run one client against it.
