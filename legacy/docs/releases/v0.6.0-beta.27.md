# Morrow Mail 0.6.0-beta.27

This beta simplifies AI Studio and Settings in both native clients and preserves each completed provider refresh page when a later scope fails.

## Changes

- **Mail refresh:** import and commit each fetched page immediately instead of collecting all scopes before saving. Each commit validates the captured mailbox connection. Refresh remains bounded to the newest page per scope; complete, resumable pagination belongs to the separate history importer.
- **AI Studio:** keep Assistant and Summaries as the primary pages, put Writing style & notes under More, and use one task picker with an action label for the selected task.
- **Settings:** keep six everyday categories and put AI connection, Search index and Writing style under Advanced setup. Direct setup links reveal the relevant section.
- **AI & privacy:** show permitted mail and information first. Collapse optional automatic actions, task permissions, limits and simulations while keeping saved automatic-assistance status visible. Existing choices, account ownership, server permissions and explicit Save/review controls remain in place.

## Validation and limits

PR #13 and PR #11 passed their macOS and Windows native CI before merging. The tagged release must repeat Node-free Rust formatting, Clippy and tests, both native packages and acceptance suites, and the Windows fictional-mail benchmark before the existing publisher makes either platform public. The publisher verifies same-run paired provenance and signs the update manifest with the existing pinned key. No test waiver applies.

Automated acceptance uses isolated fictional workspaces and provider/model fixtures. It does not establish live-account acceptance or a usability study with office users. Full provider delta/deletion synchronization, attachments and CID images remain unsupported. Manual Windows visual/accessibility, clean-machine and live-account acceptance remain outstanding.

macOS is ad-hoc signed without Apple notarization; Windows is unsigned. This is an experimental prerelease.

## Install and update

Download the macOS arm64 or Windows x64 ZIP, or use the explicit in-app update flow with its signed manifest. Back up the separate mailbox workspace before updating and do not run two clients against the same workspace simultaneously.
