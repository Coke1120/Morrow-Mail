# Morrow Mail 0.6.0-beta.25

This beta combines the Windows native layout work from PR #8 with the AI Studio and Sent writing-style changes from PR #9.

## Changes

- **Windows mail and compose:** mailbox controls and paging stay with the message list; message actions remain above the scrolling reader. Resizing Reader below keeps room for message rows. The composer has a bounded width and visible save/send actions outside its scrolling form.
- **Windows Settings:** a native Start here path guides account connection, optional model setup and AI permission review.
- **AI Studio:** choose a mailbox within Studio on macOS or Windows. All accounts shows saved summaries with their mailbox labels. Local simulation previews apply to the account that produced the preview.
- **Email Brain:** review downloaded Sent samples with Learn Now, or opt into daily style proposals while the app runs. Existing weekly consent remains weekly. Dismissing an unchanged proposal avoids repeating its paid analysis. Style application still requires explicit approval and never sends mail. Windows keeps the cancel control available during analysis.

## Validation and limits

Both PRs passed macOS and Windows native CI before merging. The combined main source passed both native jobs, including the Windows UI fixture and fictional-mail benchmark. The tagged release must repeat Node-free Rust checks, both native packages and acceptance suites, and the Windows benchmark. The publisher requires paired artifacts from that tag and a signed update manifest before either download becomes public. No test waiver applies.

The fixture checks do not establish a complete Windows visual/accessibility walkthrough, clean-machine behavior, real-model quality or live-account acceptance. Style proposals use permitted downloaded correspondence and still require user review. Simulations change only the local workspace; they do not make provider changes.

macOS is ad-hoc signed without Apple notarization; Windows is unsigned. This is an experimental prerelease. Attachments and CID images remain unsupported.

## Install and update

Download the macOS arm64 or Windows x64 ZIP, or use the explicit in-app update flow with its signed manifest. Back up the separate mailbox workspace before updating and do not run two clients against the same workspace simultaneously.

Windows requires a supported Windows 10/11 x64 environment. HTML mail uses WebView2 when available and otherwise falls back to plain text. Both native platforms use the Rust service without a bundled Node runtime.
