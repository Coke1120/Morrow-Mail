## Navigation and activity recovery

- **Mail | Agent | Brain:** both native apps open in the Mail three-pane.
  Agent contains the existing Inbox Agent, Today and Skills pages; Brain contains
  persona, writing rules and categories. AI Studio remains an advanced entry,
  with temporary hints for moved pages. Account ownership and reviewed sending
  are unchanged.
- **Abandoned work:** summary, style, memory and reply jobs left running after
  cancellation, client disconnect, timeout or worker drop become cancelled or
  failed, allowing later permitted work to proceed. Startup still reconciles
  interrupted work. Activity cancellation discards unpublished results and does
  not send mail; imports retain their separate pause/resume flow.
- **Reliable cancellation:** each mailbox and work type retains its own stop
  signal. Cancelling another account or saving its reply settings cannot erase
  an earlier cancellation. Publishing a stop is ordered with the saved job
  change, preventing a delayed response from stopping newly claimed replacement
  work. Existing claim, permission, connection and late-result checks remain.
- **Native verification repairs:** the macOS confirmation call compiles with its
  required argument label. Windows cancellation fixtures close their App and
  workers before removing temporary SQLite files. Bounded Windows process
  observation can preserve a child's original handle when its verified parent
  is discovered in the same inventory window. First-acquisition failures and
  unknown exits remain failures; no missing process is treated as normal exit.

The Gmail history-authorization correction from published v0.8.1 remains:
the first history resource HTTP 401 stops for manual recovery while retaining
cached mail and the checkpoint. Normal pre-request token-expiry refresh remains.
Writing rules, Today/category behavior, skill review queues and explicitly
reviewed Inbox Agent actions are retained.

## Distribution and known limits

**macOS is ad-hoc signed without Developer ID notarization; Windows is unsigned.**
The pinned Ed25519 manifest signature binds version and archive integrity;
source binding comes from separate tag, CI and publisher provenance. It does
not provide operating-system code signing. Live-account/provider/model,
clean-machine, physical-device, manual keyboard/VoiceOver/Narrator and complete
installed-updater restart/rollback acceptance remain incomplete.

Today still retains at most 200 completion markers per mailbox and exposes the
latest 20 for reopening. Evicted eligible suggestions can reappear, and unread
suggestions do not inherit category priority for final ordering. Existing IMAP
server-identity and bounded download/synchronization limits remain; the new
mailbox improvements are not part of this release. Numbered releases do not
certify error-free operation or production readiness.

Use the paired macOS 13.5+ Apple silicon and Windows 10/11 x64 ZIPs with their
SHA-256 files, or the explicit in-app updater. Extract the entire Windows
folder. Back up the separate mailbox workspace and quit the old app before
replacing it; run only one client against that workspace. Clients using the
retired repository URL require a manual download.
