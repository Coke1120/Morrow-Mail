# Morrow Mail 0.6.0-beta.26

This beta adds three actions at the right of a mail row when you hover over it or focus it with the keyboard.

## Changes

- **Mark Read/Unread** updates the cached message's local read state without changing the provider.
- **Reply All** prepares a draft owned by the message's account. Review and send are still separate steps.
- **Delete** moves an imported message to that account's provider Trash after a destination and account review. Gmail uses its Trash operation, Outlook resolves Deleted Items by ID, and IMAP requires a selectable `\Trash` folder with MOVE, UIDPLUS and UIDVALIDITY checks. This is a recoverable Trash move, not permanent deletion.
- Existing reader and context-menu trash actions remain local. A row without a usable provider identity shows the provider Trash action disabled.

## Validation and limits

The changes were covered by fictional Gmail, Outlook and IMAP fixtures, Rust checks, macOS native acceptance and PR #10's paired native CI. The tagged release must repeat Node-free Rust checks, both native packages and acceptance suites, and the Windows benchmark before the publisher makes either platform public. No test waiver applies. No real mailbox or provider write was used in acceptance.

Continuous provider deletion synchronization and permanent deletion are not implemented. A failed or lost provider response requires checking the mailbox before retrying; Morrow never retries a move automatically. Windows visual/accessibility and live-account acceptance remain outstanding.

macOS is ad-hoc signed without Apple notarization; Windows is unsigned. This is an experimental prerelease. Attachments and CID images remain unsupported.

## Install and update

Download the macOS arm64 or Windows x64 ZIP, or use the explicit in-app update flow with its signed manifest. Back up the separate mailbox workspace before updating and do not run two clients against the same workspace simultaneously.
