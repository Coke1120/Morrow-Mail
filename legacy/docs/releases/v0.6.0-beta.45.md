# Morrow Mail 0.6.0-beta.45

This beta includes PR #20's sync feedback and local Read/Unread clarity fixes.

## Changes

- Windows preserves mailbox-scoped sync warnings across workspace refreshes, including partial failures in All accounts, and displays retry timing. Successful recovery clears the warning.
- Activity shows saved authorization and sync failures across restarts, even when authorization fails before mail fetching starts. It excludes disconnected accounts and projects fixed safe messages instead of stored provider text.
- Quota waits show their retry time. Supported legacy quota failures remain queued; missing or invalid legacy deadlines use a safe pending-retry message. History retry text no longer suggests a three-attempt limit.
- Native Read/Unread actions explicitly say they stay local. Refresh Recent Mail and settings explain that bounded refresh may leave older downloaded messages with an earlier server state. Activity's timestamp describes a local status check, not the last mailbox sync.

Existing retry scheduling and bounded provider scopes remain in place. This release does not add provider write-back or a complete historical status mirror.

## Validation and limits

Fresh tagged macOS and Windows builds, Node-free Rust formatting, strict all-target Clippy and locked tests, full macOS production-service acceptance, the Windows fresh/owned/restart UI walkthrough and fictional-mail benchmark must pass before either download is public. The existing publisher verifies same-run/same-attempt platform artifacts and signs the update manifest against the pinned public key. No test waiver applies.

Regression checks cover persisted safe sync errors, runtime restart, account filtering, successful recovery, indefinite history retry wording, valid/missing/invalid legacy quota deadlines, and Windows combined/selected-account warnings, retry timing and current-operation error precedence. Tagged CI and public-download verification are recorded in VERIFICATION.md.

Checks use fictional mail/providers and isolated temporary workspaces. No real mail, calendar event or paid-model request is submitted. Full live-account/provider/model, real external HTTPS image fetching, physical-pointer/accessibility, clean-machine and complete installed-updater restart/rollback acceptance remain incomplete. The previously recorded intermittent Windows reader initialization timeout remains unresolved. macOS is ad-hoc signed without notarization; Windows is unsigned. This is an experimental prerelease.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. Keep the separate mailbox workspace backed up and run one client against it.
