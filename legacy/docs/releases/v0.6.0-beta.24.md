# Morrow Mail 0.6.0-beta.24

This beta combines the macOS first-use improvements from PR #5, service and updater review fixes from PR #6, and the AI Studio layout fix from PR #7.

## Changes

- **Start here on macOS:** connect a mailbox, optionally test a local or hosted chat model, and review AI permissions. Settings explains save behavior, and blocked Studio actions link to the relevant Model or Permissions settings.
- **Assistant context:** choose direct Assistant tasks and search permitted downloaded mail by sender or subject. Combined-mailbox selection uses an account-qualified UI ID while AI requests retain the original provider message ID and owner.
- **Service and provider safety:** reject stale OAuth callbacks without replacing newer connections; keep a busy callback retryable. Index historical-import cursor hashes, drain due scheduled sends in one tick, refresh Gmail labels from mutation responses, recheck Out of Office immediately before a provider write, and wait for a previous workspace writer during rapid relaunch.
- **Safer updates:** wait for the authenticated Rust service to become ready, restore the previous app after failed startup, and reclaim the downloaded ZIP and older marked backups after successful installation.
- **macOS layout:** keep AI Studio inside the available content height after selecting an account so the header and sidebar stay visible.

## Validation and limits

The tagged release must pass the existing macOS and Windows jobs: Node-free Rust formatting, strict Clippy, locked tests, native packaging and platform acceptance. Windows also runs its fictional-mail benchmark. The publisher requires same-run paired artifact provenance and a signed update manifest before either package becomes public. No test waiver applies.

PR #5, #6 and #7 each passed both native CI jobs before merging. Their isolated checks use fictional workspaces; tagged CI validates the combined release source. Manual first-use and complete Windows visual/accessibility acceptance remain separate.

The automated reader checks cover isolation, blocked requests, URL schemes and message replacement, but not the complete cancel/approve interaction for image consent and link review. Out of Office performs a final read before writing; a provider change after that read can still race when the provider offers no conditional revision. Update directories created before the target marker remain untouched when ownership cannot be established.

macOS is ad-hoc signed without Apple notarization; Windows is unsigned. Clean-machine, complete accessibility/IME/DPI and live-account acceptance remain incomplete. This is an experimental prerelease. Attachments and CID images remain unsupported.

## Install and update

Download the macOS arm64 or Windows x64 ZIP, or use the explicit in-app update flow with its signed manifest. Back up the separate mailbox workspace before updating and do not run two clients against the same workspace simultaneously.

Windows requires a supported Windows 10/11 x64 environment. HTML mail uses WebView2 when available and otherwise falls back to plain text. Both native platforms use the Rust service without a bundled Node runtime.
