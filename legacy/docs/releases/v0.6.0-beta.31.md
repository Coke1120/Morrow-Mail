# Morrow Mail 0.6.0-beta.31

This beta automatically saves Gmail labels and Outlook/IMAP folder names locally, so both native sidebars can show and filter them immediately after reopening Morrow. Browse/Refresh is no longer a required download step.

## Changes

- **Automatic folder discovery:** new and reconnected mailboxes are discovered by the five-second metadata worker. Successful catalogs refresh every 15 minutes while Morrow runs, independently of the mail-download preference.
- **Local and offline names:** catalogs are stored per account in encrypted local settings and restored at startup. Sidebar filtering uses these saved names. Settings status polling restores catalogs while preserving unsaved credentials/preferences, mail rows, paging and selection.
- **Recovery:** read failures retain saved names. Transient network/provider failures and recognized quota responses use durable backoff; daily quota responses wait 24 hours. Authorization and malformed-response failures require reconnect or optional Refresh. Reconnect starts fresh retry state and drops obsolete authorization results.
- **Reviewed organization:** create, rename, delete, hierarchy moves and message moves retain the existing account-bound reviews, write permissions and fresh provider validation. Cached names do not authorize writes.

## Validation and limits

The release uses the existing paired workflow and publisher. Both macOS and Windows must pass the complete Node-free Rust checks, native packaging/acceptance, Windows fresh/owned/restart UI, reader/persistence checks and the fictional-mail benchmark before either download becomes public. Same-run provenance, checksums and the manifest signature against the existing pinned update key remain required. No test waiver applies. Tagged CI and public-asset verification are recorded in VERIFICATION.md.

The folder-cache regression covers account isolation, nested names, encrypted restart persistence, offline retention, retry pacing, authorization/malformed blocking, reconnect and disconnect isolation. Tests use isolated fictional workspaces, loopback TLS provider fixtures and generated updater apps/keys. They do not establish complete live-account, clean-machine, accessibility or a real installed-update walkthrough acceptance.

Folder discovery downloads names, not every message or attachment. Mail retains the existing bounded Sync and resumable history-import scopes; Spam/Trash are excluded from All Mail history. Continuous provider delta/deletion reconciliation, attachment/CID viewing, cross-account transfers and bulk message moves remain unsupported. Provider-write failures never retry automatically. The earlier public beta.30 Parallels walkthrough is not a manual walkthrough of this new release.

macOS is ad-hoc signed without notarization; Windows is unsigned. Full live-account acceptance remains outstanding. This is an experimental prerelease.

## Install and update

Use the paired macOS arm64 / Windows x64 ZIPs or the explicit in-app update flow. Older macOS versions predating the beta.30 update-quit fix may still require one manual Quit during this upgrade. Keep the separate mailbox workspace backed up and run only one client against it.
