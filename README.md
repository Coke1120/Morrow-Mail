# genmail-rea

Private rewrite of GenMail Exact (Electron host). Pre-rebrand — not the public [Morrow-Mail](https://github.com/Coke1120/Morrow-Mail) line.

## Run

```bash
npm install
npm start
```

Secrets stay in macOS Keychain (`genmail-exact` service) or env (`GENMAIL_AI_API_KEY` / `XAI_API_KEY`). Do not commit API keys or mailbox caches.
